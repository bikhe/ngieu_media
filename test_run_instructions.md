# Инструкция по тестовому запуску проекта через Docker

Данное руководство поможет вам развернуть и протестировать все компоненты системы «Биржа СМИ» (бэкенд API, базу данных PostgreSQL, Telegram-бот, веб-панель администратора и мобильное веб-приложение) на вашем локальном компьютере с использованием Docker и Docker Compose.

---

## 1. Подготовка и требования

Перед началом убедитесь, что на вашем компьютере установлены:
1. **Docker** (версии 20.10+)
2. **Docker Compose** (версии 2.0+)

А также убедитесь, что следующие порты свободны:
- `8000` — Бэкенд API (Django)
- `3000` — Панель администратора (React Admin)
- `5173` — Мобильное веб-приложение (React Mobile Web)
- `5432` — База данных (PostgreSQL)

---

## 2. Настройка конфигурации (`.env`)

Все необходимые переменные окружения уже преднастроены для локальной разработки, но вы можете проверить их значения:

1. **Бэкенд** (`backend/.env`):
   - Убедитесь, что `DB_HOST=db` (это имя сервиса базы данных внутри сети Docker).
   - Если вы планируете тестировать интеграцию с Telegram, замените `TELEGRAM_BOT_TOKEN` вашим токеном от BotFather. В противном случае бот-контейнер выдаст предупреждение на старте, но остальные сервисы будут работать без ошибок.

2. **Панель администратора** (`admin-web/.env`):
   - Должна содержать: `REACT_APP_API_URL=http://localhost:8000/api`

3. **Мобильное веб-приложение** (`mobile-web/.env`):
   - Должна содержать: `VITE_API_URL=http://localhost:8000/api`

---

## 3. Запуск контейнеров

Откройте терминал в корневой директории проекта и выполните команду для сборки образов и запуска контейнеров в фоновом режиме:

```bash
docker compose up -d --build
```

Docker Compose автоматически скачает необходимые базовые образы, соберет образы для бэкенда и фронтендов, создаст общую сеть и запустит все сервисы.

---

## 4. Инициализация Базы Данных и создание Администратора

Миграции базы данных применяются автоматически при старте контейнера бэкенда (`backend`).

Для того чтобы войти в панель администратора, вам нужно создать суперпользователя. Выполните в терминале следующую команду:

```bash
docker compose exec backend python manage.py createsuperuser
```

Вам будет предложено ввести:
- **Username** (например, `admin`)
- **Email address** (можно оставить пустым, нажав Enter)
- **Password** (минимум 8 символов, при вводе символы не отображаются)
- **Confirm password**

После успешного создания вы сможете зайти в административную панель Django и React-панель.

---

## 5. Доступ к запущенным сервисам

После успешного запуска вы можете открыть следующие ссылки в вашем браузере:

*   **Панель администратора (React):** [http://localhost:3000/](http://localhost:3000/)
    *   *Здесь организаторы могут создавать заявки, а администраторы управлять пользователями и техникой.*
*   **Мобильное веб-приложение (Vite):** [http://localhost:5173/](http://localhost:5173/)
    *   *Интерфейс для исполнителей (СМИ, фотографов, видеографов), где они могут брать задачи в работу.*
*   **Панель Django Admin (бэкенд):** [http://localhost:8000/admin/](http://localhost:8000/admin/)
    *   *Используйте учетные данные суперпользователя, созданные на шаге 4, чтобы управлять базой данных напрямую.*
*   **Документация REST API (Swagger/DRF):** [http://localhost:8000/api/](http://localhost:8000/api/)

---

## 6. Полезные команды для управления

*   **Проверка статуса контейнеров:**
    ```bash
    docker compose ps
    ```
*   **Просмотр логов в реальном времени:**
    ```bash
    docker compose logs -f
    ```
    *(Если хотите посмотреть логи конкретного сервиса, например бэкенда: `docker compose logs -f backend`)*
*   **Остановка всех контейнеров:**
    ```bash
    docker compose down
    ```
    *(База данных сохранится в именованном томе `postgres_data` и не сотрется при остановке).*
*   **Остановка с удалением всех данных базы данных (очистка):**
    ```bash
    docker compose down -v
    ```
